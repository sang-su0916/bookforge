# topic 모드 — 주제 한 줄에서 책 한 권까지

입력이 주제·아이디어뿐일 때의 콘텐츠 생산 절차. 산출물은 SKILL.md의 P1 완료 기준(outline.json + chapters/*.md)이다.

## 1. 조사

먼저 [../references/lbiz-editorial-standard.md](../references/lbiz-editorial-standard.md)를 읽고 주제에 대해 조사 노트를 만든다(`<book_dir>/research.md`, 책에는 미포함).

- `research.md`에는 조사 기준일, 유튜브 검색 조건과 당시 상위 1~5개, 최신 공식 원문 목록, Korean Law MCP 조회 결과, 주장별 사실 확인, LBiz 문체 브리프를 구분해 기록한다.
- 유튜브 상위 결과는 독자의 질문·제목·도입·구성 경향을 파악하는 용도다. 광고·중복·무관한 결과를 제외한 기준과 순위를 기록하고, 사실 근거로 인용하지 않는다.
- 세무·법률·노무·지원사업·사회보험처럼 바뀌는 내용은 해당 주무부처의 가장 최신 공식 원문과 시행일을 확인한다. 한국 법령은 Korean Law MCP로 법령명·조문·하위법령·시행일을 먼저 확인한다.
- 유튜브 메타데이터·자막이나 차단된 공식 페이지 확보에는 `insane-search`를 사용한다. 접근 실패나 로그인·유료벽은 우회 성공으로 꾸미지 않고 미확인으로 기록한다.
- 수치·통계·기한·요건·고유 사건은 출처와 적용 범위를 확인한 것만 본문에 쓴다. 확인하지 못한 수치는 빼고, 서로 다른 공식 자료가 충돌하면 최신 유효 원문이 정리될 때까지 단정하지 않는다.
- 세무·법률·노무·지원사업의 사실 조사는 사용자가 속도를 요구해도 생략하지 않는다. 순수 에세이처럼 사실 근거가 불필요한 항목은 `해당 없음`과 이유를 기록한다.

완료 기준: 장 후보 6개 이상을 뒷받침할 재료가 있고, 변동 가능한 주장마다 현재 유효한 공식 근거와 확인 기준일이 연결되어 있으며, 유튜브 자료와 사실 근거가 분리돼 있다.

## 2. 목차 설계

스타일별 목차 문법이 다르다 — 선택한 스타일의 `styles/<스타일>/STYLE.md` 정체성·지면 템플릿 절을 읽고 장 구조를 정한다:

- practical: 반복 단위(패턴·활용·용어 N개)를 장으로 묶는 구조가 강하다
- insight/business: Executive Summary 성격의 1장 + 본론 + 시사점 마무리
- academic: 서론(문제 제기)→본론(장별 논점)→결론, 절 번호 위계 활용
- essay: 주제 궤적을 따라 흐르는 글(꼭지) 묶음
- magazine: 피처(기사) 단위 — 서로 다른 각도의 꼭지들

`outline.json`에 장별 `file`·`title`·`summary`를 채운다. summary는 도비라에 그대로 실린다 — 1~2문장, 그 장이 답하는 질문을 담는다.

분량 산정: short = 5~7장 × 본문 2,000~3,000자, standard = 8~12장 × 3,000~4,500자.

## 3. 장별 집필

장마다 `chapters/ch-NN.md`를 SKILL.md의 콘텐츠 계약 문법으로 쓴다.

- 첫 줄 `# {outline의 title}` 일치 필수
- 스타일의 STYLE.md가 규정한 구성 요소를 활용한다(키 스탯은 ::: stat, 팁 박스는 ::: tip, 인용은 > 또는 ::: quote)
- 표·리스트·콜아웃을 장당 2개 이상 섞어 지면 리듬을 만든다 (essay 제외 — essay는 문단·인용 중심)
- 대표님께 설명하는 정중한 `합니다`체를 기본으로 하되 상담 장면·짧은 질문·쉬운 비유를 섞는다. 과장, AI 자기언급, [LBiz 문체 기준](../references/lbiz-editorial-standard.md)의 AI투 표현은 금지한다.

장이 많으면 병렬화할 수 있다 — Claude Code 환경이면 [../references/orchestration.md](../references/orchestration.md) 참조. 단일 에이전트면 순서대로 쓴다.

완료 기준: 모든 장 파일 존재 + 각 장이 계약 문법만 사용 + 총 분량이 프리셋 범위를 감당(short는 도비라·차례 포함 30쪽을 넘겨야 하므로 본문 합계 1.2만 자 이상).
